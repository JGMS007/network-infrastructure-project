# network-infrastructure-project
Academic IT Infrastructure Project, including logical topology, IP addressing, and server configuration in Cisco Packet Tracer.🌐
This project was developed as part of the IT Infrastructure module, focusing on the planning and implementation of a secure and functional corporate network.

## 🚀 Technologies and Tools
* **Cisco Packet Tracer:** Network simulation and analysis.

* **Protocols:** TCP/IP, DNS, DHCP, HTTP, SMTP.

* **Systems:** Configuration of Windows and Linux servers.

## 📋 Project Scope
The project consisted of creating an infrastructure for Caine Consulting, encompassing:
* **Network Segmentation:** Division by departments (Finance, HR, IT, etc.) using subnet masks.

* **Implemented Services:** - DNS Server (`www.caineconsultoria.com`)

- DHCP Server for IP automation.

- Email and HTTP Server.

* **Security:** Border Router configuration and routing table analysis.
